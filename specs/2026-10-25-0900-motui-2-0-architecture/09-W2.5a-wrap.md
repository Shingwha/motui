## 目标

把散落的 59 处 `.fit()` 收成显式策略，**本波不改任何默认视觉**：

1. `WrapMode` 五值可用：`WORD/CHAR/ELLIPSIS/CLIP/OVERFLOW`；
2. `Line.reflow(mode, width) -> list[Line]` 是唯一换行/截断入口；`Line.clip(mode, width) -> Line` 是单行入口；
3. `fit` 降为私有（`_fit`），所有调用点迁移；
4. `Table(cell_wrap=)`、`Diff(wrap=)`、`Editor(wrap=)` 参数落地，默认值保持当前行为（Table=WORD、Diff=ELLIPSIS、Editor=WORD）；删除 `Table(wrap: bool)`；
5. `kernel/text.py` 增加 `text.*` 度量别名（`width/wrap/spans/fit/ellipsize/index_at/bounds`），旧名保留到 W5；
6. 57 字节 golden 与语义 golden **逐字节不变**。

**本波结束：全量 pytest 绿；byte golden/hash 不变；semantic 57 不变；`grep "\.fit(" src/motui` 只剩私有 `_fit` 内部调用（0 个对外调用）。**

## 工单（按序，每步一个 commit）

### T1 `Line.reflow` / `Line.clip` / `_wrap_chars`

- `kernel/cell.py`：
  - `fit` 改名 `_fit`（私有；保留同样的省略号语义）；全文件内部引用改名。
  - 现有 `clip(width)` 改名 `_cut_width(width)`（硬裁）；`Surface.of/clipped`、`Painter` 若调用它，改用 `cut_line(row, 0, width)` 或 `_cut_width`。
  - 新增：
    ```python
    def reflow(self, mode: WrapMode, width: int) -> list[Line]
    def clip(self, mode: WrapMode, width: int) -> Line  # reflow(mode,width)[0]
    ```
    语义：
    - WORD：`wrap_line(self, width)`，每行再 `_fit(width)` 收尾；空行/width≤0 → `[Line()]`。
    - CHAR：`_wrap_chars(self, width)`（新增，按 display column 逐 cell 切，保留样式/payload），每行 `_fit(width)`；空行/width≤0 → `[Line()]`。
    - ELLIPSIS：`[self._fit(width)]`。
    - CLIP：`[cut_line(self, 0, width)]`（width≤0 → `[Line()]`）。
    - OVERFLOW：`[self]`（即使宽 > width）。
    - 未知 mode：`ValueError`。
  - `_wrap_chars`：用 `kernel.text` 的 cell 扫描（`_cell_spans` 或 `index_*`）按列累加，边界不拆 cluster；复用 `slice_line`。
- `kernel/text.py`：增加模块级别名（旧名保留）：
  ```python
  width = visible_width
  wrap = wrap_text
  spans = wrap_spans
  fit = fit_text
  ellipsize = ellipsize_tail
  index_at = index_pair_at_columns
  bounds = index_bounds_at_columns
  ```
  更新 `__all__`（新名 + 旧名）。
- 测试 `tests/kernel/test_cell.py`：
  - 5 模式 × 宽度 0/1/2/3/7 × 纯 ASCII/CJK/emoji/组合字符；
  - 每个返回行 ≤ width（OVERFLOW 除外）；WORD/CHAR 1..N，其余恰好 1；
  - 样式/payload 跨行保留；
  - 宽字符不拆半；宽度 1 的 CJK 行仍 ≤1（省略/裁剪）。
- 只允许改：`kernel/cell.py`、`kernel/text.py`、`tests/kernel/test_cell.py`、`tests/kernel/test_text.py`、`tests/kernel/test_surface.py`（只改 `_fit`/`clip` 引用）。
