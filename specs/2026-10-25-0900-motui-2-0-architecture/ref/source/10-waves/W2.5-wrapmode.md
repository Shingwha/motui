# W2.5 · 换行策略：WrapMode + Line.reflow

> 上级：`README.md`　依赖：`W2-render-contract.md`　下一波：`W2.6-horizontal-scroll.md`
> 状态：ready

## 1. 目标

把散落在 59 处 `.fit()` 的换行/截断收成一个显式策略：

- `WrapMode`（WORD/CHAR/ELLIPSIS/CLIP/OVERFLOW）；
- `Line.reflow(mode, width)` 唯一入口；
- 2.0 只改两处默认：**代码块 截断→换行**、**Input 多行→单行水平跟随**；
- `Table`/`Diff`/`Editor` 暴露 `wrap` 参数。

## 2. 为什么

- 1.x 的换行/截断是每个组件各自决定；`fit` 同时承担“截断”和“让行合法”。
- 三处静默丢内容：Markdown 代码块、`Diff`、`Table(wrap=False)`。
- 行业没有全局默认：正文换行、代码/数据行裁切、单行输入水平滚动（ADR-012）。

## 3. 契约

```python
class WrapMode(Enum):
    WORD = "word"; CHAR = "char"
    ELLIPSIS = "ellipsis"; CLIP = "clip"; OVERFLOW = "overflow"

class Line:
    def reflow(self, mode: WrapMode, width: int) -> list[Line]: ...
```

| 模式 | 复用 | 行数 |
|---|---|---|
| WORD | `text.wrap` / `wrap_spans` | 1..N |
| CHAR | 新增 `_wrap_chars`（逐字符，复用 `width`） | 1..N |
| ELLIPSIS | `fit` / `ellipsize` | 1 |
| CLIP | `cut_line(line, 0, width)` | 1 |
| OVERFLOW | 原样返回 | 1 |

## 4. 默认值

| 组件 | 参数 | 2.0 默认 | L1 可选 |
|---|---|---|---|
| Text / Markdown 正文 | `wrap=` | WORD | — |
| Markdown 代码块 | `code_wrap=` | **WORD** | OVERFLOW |
| Diff | `wrap=` | ELLIPSIS | OVERFLOW |
| Table | `cell_wrap=` | WORD | OVERFLOW |
| List/Tree/Select/Nav/Tabs/Menu/Status | 固定 | ELLIPSIS | — |
| Input | `wrap=` | **OVERFLOW（单行）** | — |
| Editor | `wrap=` | WORD | OVERFLOW |

## 5. 不变量

1. WORD/CHAR 1..N；其余恰好 1。
2. 单行模式保持逻辑行 ↔ 视觉行 1:1。
3. OVERFLOW 可超宽；`Surface.width` 变内容宽度，容器裁剪。
4. `WrapMode` 不进 `Constraints`；改变它必须 `touch()`。
5. 不支持的模式构造时 `ValueError`。
6. 宽度 0/负数、emoji/CJK/组合字符走现有测量根。

## 6. 任务

1. `kernel/text.py`：`WrapMode`、`_wrap_chars`、`text.*` 命名空间（`width/wrap/spans/fit/ellipsize/index_at/bounds`）。
2. `kernel/cell.py`：`Line.reflow`；`fit` 降为私有。
3. 迁移 59 处 `.fit()`：
   - 行式组件 → `reflow(ELLIPSIS, w)`；
   - Text/Markdown 正文 → `reflow(WORD, w)`；
   - 代码块 → `reflow(WORD, w)`（默认改）。
4. `Table(cell_wrap=)`、`Diff(wrap=)`、`Editor(wrap=)`；删除 `Table(wrap: bool)`。
5. `Input` 单行水平跟随：游标几何 + `scroll_x` 内部状态；`Editor` 仍走 `TextBuffer` 的 wrap 记忆。
6. 测试：5 模式 × 宽度 1/2/3 × emoji/CJK；代码块长行完整可读；Input 200 字符仍一行。
