# W2.6 · 横向滚动 L1（不换行内容）

> 上级：`README.md`　依赖：`W2-render-contract.md` `W2.5-wrapmode.md`
> 状态：ready

## 1. 目标

在 2.0 提供**不换行内容**的横向滚动：

- `Scroll` 2D（`x`/`y` 两个 `Axis`）；
- `ScrollPanel(axis="x"|"y"|"both")`；
- `Scrollbar(axis=Axis.X)`；
- `wheel_left/right` 路由；
- `OVERFLOW` 内容（Table/Diff/代码/Editor）可放进去；
- `Hit.col` 在 `scroll.x > 0` 时映射回组件列。

**不做**：自动换行文档流的横向滚动（2.x）。

## 2. 为什么

- 1.x `Table(wrap=False)` 只能被裁掉，右边永远看不到。
- `decoder.py` 已解码 `wheel_left/right`，只是没有消费者。
- 2.0 的 `Surface.width = 内容宽度` 让 `OVERFLOW` 合法；只差一个裁剪+偏移的容器。

## 3. 契约

```python
@dataclass(frozen=True, slots=True, kw_only=True)
class Axis:
    offset: int = 0
    content: int = 0
    viewport: int = 0
    sticky: bool = False

@dataclass(frozen=True, slots=True, kw_only=True)
class Scroll:
    x: Axis = Axis()
    y: Axis = field(default_factory=lambda: Axis(sticky=True))
```

- `Axis` 的 `clamp/max_offset/reveal/thumb` 只写一遍；
- `sticky` 只对 y；
- `ScrollPanel` 渲染子组件后 `cut_line(row, x, x+w)`；
- `Pane`/`Document` 仍 y-only（`Scroll.x` 恒 0）。

## 4. 任务

1. `kernel/layout.py`：`Axis`/`Scroll` 2D；`ScrollState` 迁移；`Viewport` 计算 `content_width`（y-only 保持）。
2. `widgets/scroll.py`：`ScrollPanel(child, height=None, axis="both")`：
   - 子组件收到 `Constraints(width=viewport_w, max_height=...)`；
   - 子组件可返回更宽 `Surface`（OVERFLOW）；
   - 裁剪 + `Scroll.x`；
   - `wheel`/键位 action `scroll_x`。
3. `Scrollbar(axis=Axis.X)`：与 y 共用 `Scroll.thumb`；水平条挂 pane 底部或 ScrollPanel。
4. `wheel_left/right` 路由：最近 `Scrollable`（ScrollPanel/Pane）消费；不误滚文档。
5. `Hit.col`：`component_col = Hit.col + Scroll.x.offset`（在 `descend` 前）。
6. `OVERFLOW` 组件：`Table(cell_wrap=OVERFLOW)`、`Diff(wrap=OVERFLOW)`、`code_wrap=OVERFLOW`、`Editor(wrap=OVERFLOW)`。
7. 测试：
   - 200 列 Table 放入 80 列 ScrollPanel，可滚到最右列；
   - x/y 独立 clamp；
   - wheel 只作用于横向容器；
   - hit 映射；
   - 非 OVERFLOW 页面字节不变。

## 5. 不变量

1. 每轴 `0 <= offset <= max(0, content - viewport)`。
2. `Scroll.x.offset != 0` 仅当存在 OVERFLOW 且容器允许 x。
3. `Surface.width` = 内容宽度；可见宽 = `min(内容, 视口)`。
4. 选择/`extract` 仍文档空间；x 只影响高亮裁剪。
5. 横向条与竖向条共用 `thumb()`。

## 6. 门禁

- `pytest` 全绿；
- 宽表最右列可达；
- x/y 独立；
- `framebench` 不劣化；
- 非 OVERFLOW 页面字节不变；
- `examples/wide_table.py` 通过。

## 7. 退出条件

- [ ] `ScrollPanel(axis="x")` 可用；
- [ ] 水平条 + wheel 路由；
- [ ] hit 映射正确；
- [ ] 文档流仍 y-only；
- [ ] 无第二套 thumb 公式。

## 8. 回滚

- 本波是加法（新组件 + 可选参数）；回退只删 `ScrollPanel` 的 x 分支与 `Scrollbar(axis=X)`，不影响 y。
