# W2.6b · OVERFLOW 生产者 + 宽表示例 + 水平 pane 条

> 分支 `2.0/w2.6b-overflow`；前置：W2.6a 已合并（`e17dae2`）；写入范围：`src/motui/widgets/{table,diff,markdown/component,textfield}.py`、`src/motui/app/scrollbar.py`、`examples/wide_table.py`、`tests/widgets/{test_data,test_diff,test_markdown,test_editing}.py`、`tests/app/test_scrollbar.py`、`tests/test_examples.py`、`tools/api-2.0.txt`
> 权威：`ref/source/10-waves/W2.6-horizontal-scroll.md` §3–6、`06-widgets.md` §8

## 目标

让 W2.6a 的横向容器有真实内容可滚：

1. `Table(cell_wrap=OVERFLOW)`：自然列宽、返回自然宽 `Surface`（可 > `Constraints.width`）；
2. `Diff(wrap=OVERFLOW)`：长行原样、自然宽 Surface；
3. `Markdown(code_wrap=OVERFLOW)`：代码行原样、文档 Surface 宽度为最大内容宽；
4. `Editor(wrap=OVERFLOW)`：逻辑行不折行、自然宽 Surface（光标/选择尽量保持；做不到就明确报告，不静默假装）；
5. `Scrollbar(axis=Axis.X)`： pane 底部水平条（基于 ScrollPanel 的 x 状态；`target=` 显式传入）；
6. `examples/wide_table.py`：200 列宽表在 80 列 ScrollPanel(axis="x") 滚到最右列；
7. 默认（WORD/ELLIPSIS）字节不变：57 byte + 57 semantic + hash 不变。

**本波结束：宽表最右列可达；四种 OVERFLOW 生产者返回自然宽；水平条可用；默认页面零字节变化。**

## 前置上下文

- 必读：`ref/repo-map.md` → `ref/interfaces.md` → `handoff/W2.6a-scrollx.md` → 本工单。
- 基线：`uv sync --locked`；`pytest`（1380 passed）；`golden --check`（57）；`semantic --check`（57）；`framebench` hash `e7ca544b…`。
- 现状：
  - `ScrollPanel` 已支持 x/both；它读 `surface.width` 作为 `content_width`。
  - `Table.render` 以 `c.width` 计算预算并 `Surface.clipped(rows, c.width)`；`_layout(width)`/`_wrap_budgets` 里有自然宽与 shrink 逻辑。`cell_wrap=OVERFLOW` 目前在 `_cell` 里按 ELLIPSIS 处理（W2.5a）。
  - `Diff.render` 按 `wrap` reflow，最后 `Surface.clipped(rows, c.width)`；`OVERFLOW` 的 `reflow` 返回原行，但 Surface 仍被裁。
  - `Markdown.render` 最后 `Surface.clipped(rows, c.width)`；`code_wrap=OVERFLOW` 的代码行被裁。
  - `Editor` 继承 `_TextField`，`_rows_for` 用 `visual_rows(width, indent)`（始终按 width 折行）；`_wrap=OVERFLOW` 时最终走 `clip(OVERFLOW,width)`，但 buffer 几何已经折行。
  - `Scrollbar` 只注册 `Chrome("right", size, paint, scope="body")`；`Chrome` 的 `scope="body"` 只允许 left/right；底部条必须用 `scope="pane"`（`edge="bottom"`，size=1），paint 返回 1 行、宽 = pane 宽。
  - `ScrollPanel` 暴露 `x_offset/total_columns/viewport_width/scroll_x_by`；`ScreenLayout` 没有 x 状态。
- 已知坑：
  - `Surface.width` 是内容宽度；Table/Diff/Markdown/Editor 的 OVERFLOW 分支必须返回 `width >= 最大行宽`，不能再用 `Surface.clipped(rows, c.width)`。
  - 正常默认分支必须保持 `Surface.clipped(rows, c.width)`，否则 golden/hash 会变。
  - Table 的自然宽：每列最大内容宽（可受显式 `max_col_width` 限制，但不受 viewport 宽限制）；边框/分隔线/表头都按自然宽生成；`max_height` 仍截断。
  - Diff 的 `@@`/elision 行也要按自然宽；`Surface` 宽度取 `max(c.width, max row width)`。
  - Markdown 的 span index/hit 列是行内列；自然宽 Surface 不影响 hit。`_stamp_key`/stream cache 键要能区分 OVERFLOW（code_wrap 已在键里）。
  - Editor 的 OVERFLOW：逻辑行（`value.split("\n")`）一行一条；光标行/列用 `_buf.row`/`_buf.col`；`row_body` 画光标；选择带若无法精确映射，至少保证光标/文本正确，并在 handoff 明确限制。
  - `Scrollbar(axis=X)` 需要 ScrollPanel 的 x 状态；构造参数加 `target: ScrollPanel | None = None`；`axis=X` 时若 target 为 None，尝试在 pane 的 document 中找唯一的 ScrollPanel（`isinstance` 在 app 层允许，因为 app 可以 import widgets）；找不到抛 `ValueError`。paint 用 `target.x_offset/total_columns/viewport_width` 和 `ScrollAxis.thumb`。
  - 底部条 `Chrome("bottom", size, paint, scope="pane")`；paint 返回 1 行宽 = pane 宽；track/thumb glyphs 与垂直条共用。
  - 非横向默认页面零变化：只在 `OVERFLOW`/`axis=X` 分支走新路径。

## 工单（按序，每步一个 commit）

### T1 Table `cell_wrap=OVERFLOW`

- `widgets/table.py`：
  - `_layout(width)`/预算：当 `self.cell_wrap is WrapMode.OVERFLOW` 时，列宽取每列内容自然宽（受 `max_col_width` 限制，若设置），不按 viewport shrink；生成完整网格行。
  - `render`：OVERFLOW 时返回 `Surface.of(rows, max(c.width, natural_width), pad=False)`（或 `Surface.clipped` 到 natural_width）；其它模式保持 `Surface.clipped(rows, c.width)`。
  - `_revision` 已含 `cell_wrap`；memo 键要包含自然宽（若计算依赖内容，已由 revision/rows 覆盖）。
- 测试 `tests/widgets/test_data.py`：一个 200 字符单元格的 Table，`cell_wrap=OVERFLOW` 在 `Constraints(width=80)` 下 `surface.width > 80`，行文本完整；`WORD/ELLIPSIS` 仍 ≤80。
- 只允许改：`widgets/table.py`、`tests/widgets/test_data.py`。
- 验证：`uv run pytest -q tests/widgets/test_data.py`；`golden/hash` 不变。

### T2 Diff `wrap=OVERFLOW`

- `widgets/diff.py`：
  - `render`：OVERFLOW 时 `Surface.of(rows, max(c.width, max(row.width)), pad=False)`；其它模式保持 `Surface.clipped`。
  - 缓存键已含 wrap；`max_height` 截断保持。
- 测试 `tests/widgets/test_diff.py`：200 字符行 + OVERFLOW → surface 宽 >80、完整；ELLIPSIS → ≤80 且带 `…`。
- 只允许改：`widgets/diff.py`、`tests/widgets/test_diff.py`。
- 验证：`uv run pytest -q tests/widgets/test_diff.py`。

### T3 Markdown `code_wrap=OVERFLOW`

- `widgets/markdown/component.py` `render` 末尾：
  - 若 `self.code_wrap is WrapMode.OVERFLOW` 且任一 `row.width > c.width`：返回 `Surface.of(rows, max(c.width, max_row_width), pad=False)`；
  - 否则保持 `Surface.clipped(rows, c.width)`。
  - 确认 `_stamp_key`/`_StreamCache` 已含 code_wrap；若没有，补上。
- 测试 `tests/widgets/test_markdown.py`：包含围栏代码的 Markdown，`code_wrap=OVERFLOW` 在 width=40 下 surface 宽 >40 且代码完整；`WORD` 仍 ≤40；`ELLIPSIS` 带 `…`。
- 只允许改：`widgets/markdown/component.py`、`tests/widgets/test_markdown.py`。
- 验证：`uv run pytest -q tests/widgets/test_markdown.py`。

### T4 Editor `wrap=OVERFLOW`

- `widgets/textfield.py` `Editor`：
  - 当 `_wrap is WrapMode.OVERFLOW` 时，`_rows_for` 用逻辑行（`value.split("\n")`）一条一行；光标行/列用 `_buf.row`/`_buf.col`；每行 `row_body` 画光标；缩进/selection/mask 尽量复用现有逻辑。
  - `render` 的最终 Surface：OVERFLOW 时自然宽（`Surface.of(..., max(c.width,max_row_width), pad=False)`），否则 `Surface.clipped`。
  - 如果光标/选择的逻辑行映射无法在合理时间内正确实现：**停止并报告阻塞点**，不要静默退回折行。
- 测试 `tests/widgets/test_editing.py`：Editor 200 字符单行 + OVERFLOW → 一条逻辑行、surface 宽 >80、光标在行内；默认 WORD 仍在 80 内折行。
- 只允许改：`widgets/textfield.py`、`tests/widgets/test_editing.py`。
- 验证：`uv run pytest -q tests/widgets/test_editing.py`。

### T5 `Scrollbar(axis=Axis.X)`

- `app/scrollbar.py`：
  - 构造加 `axis: Axis = Axis.Y`、`target: ScrollPanel | None = None`（`ScrollPanel` import 自 `..widgets.scroll`；app 层可以 import widgets）。
  - `Axis.Y` 保持现有 right/body 注册与行为；`Axis.X`：
    - target 解析：显式 target；否则在 pane 的 document 中找唯一的 `ScrollPanel`（`sections` 的 component 实例）；找不到抛 `ValueError`；
    - 注册 `Chrome("bottom", size, self._paint_horizontal, scope="pane")`（size 默认 1）；

    - `handle` 的横向拖拽/轨道点击可先不实现（W4），但 `Scrollbar` 不应吞掉无关事件。

- 测试 `tests/app/test_scrollbar.py`：水平条注册在底部、thumb 位置随 `target.scroll_x` 变化；pane 宽 80、内容 200、视口 80 → thumb 长 32、offset 0 起 0、end 起 48；`Axis.Y` 行为不变。
- 只允许改：`app/scrollbar.py`、`tests/app/test_scrollbar.py`。
