## B. Input 水平跟随与 code_wrap 缓存（实现细节 / 坑）

1. **显示串 1:1**。`display` 为 `mask[0] * len(value)`（有 mask）或 `value`，随后
   `\r\n → "  "`、`\r → " "`、`\n → " "`：每个源字符恰好一个显示字符，`display` 下标
   == buffer 字符偏移。工单示例把 `\r\n` 折成一个空格（会长 1），与“替换不删除、偏移
   1:1”冲突；这里取后者：`\r\n` 画两个空格（仅显式 `insert` 可达；paste 已折成一个）。
2. **可见窗口**。`inner = width - indent`；`cursor_col = visible_width(display[:offset])`；
   `cursor_col >= inner` 时 `scroll_x = cursor_col - inner + 1`，否则 0；
   `start, end = index_pair_at_columns(display, scroll_x, scroll_x + inner)`；
   `local = clamp(offset - start, 0, len(visible))`。`index_pair` 对宽簇内部边界取簇首，
   窗口不会劈开 CJK/emoji；行尾填满且宽簇占满最后一列时从 `start` 逐簇丢弃，
   直到 `visible_width + 1 <= inner`，给光标块留一格。
3. **row_body / 选择**。`row_body(visible, local, inner, base, caret, selection=..., ...)`
   画基础样式、光标字符（或行尾 reverse 空格）与选择带；选择用 `_window_selection`
   映射成窗口字符区间（空交集为 `None`），`cursor_marked` 与共享壳同规则。hover 在行
   构造后整体 merge；最终 `line.clip(WrapMode.CLIP, width)`，绝不加 `…`。
4. **恒一行**。placeholder（空 + focused）走 hint 分支、无光标；`indent >= width` 只返回
   裁到 `width` 的 prompt；三条路径都 1 行，`max_height` 只截取不重排。OVERFLOW 下
   `cursor_position` 返回 `(0, indent + visible_width(visible[:local]))`，与 render 同一格。
5. **code_wrap 缓存**。`RenderContext` frozen，setter 用 `replace` 换 ctx；只把 mode 放进
   `revision()` 不够：cache 会按 `(text, width)` 返回旧行数，所以它自存 `_code_wrap` 并用
   `is` 比较；`_stamp/_acts` 派生自行数，键也含 mode。围栏行始终 `ELLIPSIS`；`OVERFLOW`
   代码行可超宽，`Markdown.render` 的 `Surface.clipped` 仍按 `c.width` 裁（自然宽留 W2.6）。
6. **WORD 对超长 token** 不是丢尾：`wrap_line` 契约是 over-long words hard-broken，
   所以 206 列单 token 也完整铺开；测试据此断言 `"".join(body) == line` 且无 `…`。
7. **mask**：Input 每个源字符换一个 mask 字符（工单规则），宽字符比 Editor 的
   `_mask_row`（按显示宽补 glyph）窄；Editor 路径未动。
