## dump 门禁（**有意变化**，每波由 lead 重记基线）

| 命令 | 本组要求 | 改前值（@b397633） |
|---|---|---|
| `uv run python examples/demo.py < /dev/null; echo exit=$?` | `exit=0`；dump 里能看到当前已交付的展品内容；行数**允许变化**（每波 lead 记录新值） | `exit=0`，70 行 |
| `uv run python examples/demo.py --pages` | `exit=0`；页头数 = 当波页表长度（终态 12）；**`streaming` 展品必须 dump 出完整 fixture**（dump-safe 规则）；行数每波重记 | `exit=0`，720 行，10 个页头 |

## 复核项（不进门禁，但每波报告要贴）

- `uv run python examples/demo.py --pages | grep -c '^── /'` → 页头计数
- 新展品的页头/关键文案在 dump 里的真实行（贴原文）
- 非交互路径不 sleep（库契约）：`demo.py < /dev/null` 的墙钟 < 2s

## 参考实测（非门禁）

`replay ≈ 240–500 ms`、`stream-single ≈ 4–12 ms/frame`（机器负载敏感，勿当门禁）。
