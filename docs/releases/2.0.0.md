# motui 2.0.0 — one clean surface

**2.0 is the release that removes its own scaffolding. The compatibility
arguments, the old protocol bases and the topic tour are gone; what remains
is the tree described by [CONTRACT](https://github.com/Shingwha/motui/blob/v2.0.0/docs/CONTRACT.md) and
[WIDGETS](https://github.com/Shingwha/motui/blob/v2.0.0/docs/WIDGETS.md). This is the 2.0.0 release note.**

## The shape

```python
App(theme=None, terminal=TerminalOptions(...), throttle=0.03, auto=True,
    title="", on_selection=None, handlers=None)
Runtime(terminal, *, throttle=0.03, interactive=False, theme=None)
```

`Runtime` owns the session: terminal, painter, clock, timers, pump and run
lifecycle. `Workspace` owns what is on screen: document, frame, panes,
docks, hit testing and selection. `App` composes both and runs the default
handler chain from `app/router.py`:

```
palette -> modal -> find -> toast -> controllers -> wheel -> drag
        -> mouse -> focus -> page keys -> bindings -> host
```

A host that wants another policy passes `App(handlers=...)`; a tier is a
plain `Handler(app, event) -> bool`.

## The model changes

- `Revisioned` and every `revision()` implementation are deleted. Assigning
  a public widget attribute calls `touch()`, which moves `generation` up
  the parent chain; `Section` caches rows by
  `(width, max_height, widget.generation)`. In-place list/buffer edits call
  `touch()` themselves.
- `Themed` is gone. `theme`/`styles` resolve through `Theme.group(name)` at
  render time.
- `ScrollState` is gone. `Viewport.scroll` and `ScrollPanel.scroll` answer
  an immutable `Scroll`/`ScrollAxis`; `clamp(previous_extent)` carries the
  tail-following window across content growth.
- `RowRange` is gone; pane visibility answers `RowSpan(first, last)`.
- `split`/`dock` speak only `Axis`/`Placement`; `pin`, direction strings,
  `ratios=` and `edge=` raise `ValueError`.
- `open_palette` takes a `CommandRegistry` only.

## The showcase

`python -m motui` is now one interactive page over ten scenes: the splash,
the Home tile grid and the seven sections it opens (components, layout,
motion, dashboard, terminal, themes -- the first two and last two ship as
under-construction panels this release), plus the standalone snake game and
gallery:

| Scene | What it is |
|---|---|
| `splash` | a persistent 5x7 MOTUI logo cycling Neon, Plasma, Retro CRT and Starfield until a key |
| `menu` | the Home tiles: six framed destinations, each with a live micro preview |
| `components` / `layout` / `terminal` / `themes` | under-construction panels for the next waves |
| `motion` / `snake` | the playable Canvas game (half-block square cells, food, growth, pause, game over) |
| `dashboard` | a streaming Sparkline, two ProgressBars and a table |
| `gallery` | a live Tree, Table, ProgressBar, Slider and Input |

`--pages` prints all ten as plain text; `--scene NAME --headless` prints a
deterministic frame. The semantic golden set is those ten scenes. Entering
a section wipes it in column by column; a status line pins the section and
a theme/fps note to the bottom row; `ctrl+p` opens the demo's command
palette.

## Showcase scripts

The standalone example scripts are gone; the demo is the one assembly
path. `quickstart`'s App/Text/Input opening now lives in the README, and
the `code`/`wide_table` assemblies run in the `gallery` scene
(`python -m motui --scene gallery`).
