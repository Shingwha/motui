# ADR-004 · Delete Revisioned

- **Status:** Accepted (2.0)
- **Context:** The 1.x `Revisioned` protocol required every mutable widget
  to hand-write a `revision()` snapshot. It appeared in 37 implementations
  and 44 call sites, and every snapshot had a trap: a mutable list included
  by reference could silently freeze a cached row.
- **Decision:** State changes invalidate automatically. Assigning a public
  widget attribute calls `touch()`, which increments a monotone
  `generation` along the parent chain. A section caches rows by
  `(width, max_height, revision)` only when its component answers a
  snapshot; `None` (or no snapshot at all) disables caching for that
  component.
- **Why:** Caching is on by default, the snapshot traps disappear from
  widget code, and containers no longer implement child-key arithmetic.
- **Consequences:** In-place mutation of a list or buffer requires an
  explicit `touch()`. Each mutable widget needs a "change invalidates"
  test. Snapshot values still have to use value semantics where a
  component opts into caching.
- **Alternatives:** Keep `Revisioned` (rejected); use a global dirty flag
  (rejected: missed invalidation is harder to find).
