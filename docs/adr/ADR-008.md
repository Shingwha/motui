# ADR-008 · Golden frames are semantic

- **Status:** Accepted (2.0)
- **Context:** The 1.x gate compared 57 byte hashes. A harmless SGR ordering
  change produced noise, while a wrapping or clipping regression could
  pass because the bytes stayed internally consistent.
- **Decision:** The primary gate is a VT emulator that rebuilds the cell
  grid and compares cells and attributes per topic. A small byte-level set
  remains as an extra regression check.
- **Why:** Cell-level assertions are stable against escape spelling and
  catch the wrapping, clipping and ownership bugs the byte hash missed.
- **Consequences:** The semantic snapshots were re-recorded during the
  migration and each difference was classified. The byte topics remain in
  `tests/golden/topics/` and are still checked; they are an additional
  gate, not the rendering contract. `tools/golden.py` remains the
  byte-level updater.
- **Alternatives:** Keep only byte hashes (rejected: noisy and blind to
  layout); keep only semantic snapshots (rejected during 2.0: the byte
  gate still catches escape changes the emulator ignores).
