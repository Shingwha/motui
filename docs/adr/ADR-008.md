# ADR-008 · Golden frames are semantic

- **Status:** Accepted (2.0); 2.1 ships ten scene snapshots
- **2.1 note:** The decision is unchanged; the count grew from five to ten
  scenes under the same semantic-frame format.
- **Context:** The 1.x gate compared 57 byte hashes. A harmless SGR ordering
  change produced noise, while a wrapping or clipping regression could
  pass because the bytes stayed internally consistent.
- **Decision:** The gate is a VT emulator that rebuilds the cell grid and
  compares cells and attributes per scene.
- **Why:** Cell-level assertions are stable against escape spelling and
  catch the wrapping, clipping and ownership bugs a byte hash misses.
- **Consequences:** The semantic snapshots are the only golden set in the
  clean 2.0 release: five showcase scenes under `tests/golden/semantic/`,
  produced by `tools/semantic.py`. The 1.x byte topics and
  `tools/golden.py` were removed once the semantic set covered the demo.
- **Alternatives:** Keep only byte hashes (rejected: noisy and blind to
  layout); keep both sets (rejected in the 2.0 clean-up: the byte gate
  duplicated the semantic contract and pinned the old topic tour).
