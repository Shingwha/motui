# ADR-029 · State, verbs and results are one vocabulary

- **Status:** Accepted (2.1.2)
- **Context:** The 2.1.0 widgets had grown apart: the tree root property and
  the node fold flag named what every other view called `nodes` and `open`;
  the combo box exposed a boolean flag plus `open()`/`close()` methods
  beside a state attribute; `Tabs` and `NavList` had no activation;
  `Table.take()` answered a row index while `selected` was the row;
  the select's commit switch wrote a result on every move;
  `Slider.take()` duplicated `.value`. A host could not write one
  collection loop.
- **Decision:** Seven state names carry readable state: `index`,
  `selected`, `marked`, `value`, `checked`, `open` and `text`. Six verbs
  cover mutation: `activate`, `toggle`, `select`, `move`, `advance` and
  `take`. `index` is an assignable `int` (the setter delegates to `select`;
  an empty collection answers 0) and `selected` is read-only. Only
  `activate()` and `toggle()` write a pending result; every state-changing
  verb (a move, a select, an open/close, a cursor click) clears it.
  `on_action` routes one fixed vocabulary: `prev`, `next`, `first`, `last`,
  `page_prev`, `page_next`, `activate`, `toggle`, `open`, `close`. A
  `ResultWidget` stores its result behind the `_MISSING` sentinel, so a
  legal `None` payload and an empty slot stay distinguishable internally;
  the caller uses "take was called" as the cancel signal. Results are
  uniform: a table answers the row object, a select the option value (its
  label when the payload is `None`), a tree the `TreeNode`, a strip the
  label, a form a dict, a dialog the button value. `Slider` has no `take()`.
- **Why:** One vocabulary means one host loop and one place to learn the
  rules. Cleared-on-move prevents a stale pick from being read as the row a
  host moved to. Readable state stays available without consuming a result,
  and the sentinel keeps `None` from doing double duty. The uniform result
  table removes the index-versus-row and label-versus-`Option` surprises.
- **Consequences:** `Table.take()` returns the row, not an index; existing
  callers index it themselves. `Select` loses `commit`; a form reads
  `selected`. `Tabs`, `MenuBar` and `NavList` become activatable and answer
  a label. `Slider` loses `take()`. A host that moved a cursor after an
  activation must activate again; the move cleared the pick.
- **Alternatives:** Keep per-widget names (rejected: three spellings of
  open); push results through callbacks (rejected: ADR-023); make `take()`
  read state without clearing (rejected: two read semantics); use `None`
  as the empty sentinel (rejected: a cancelled dialog is a real `None`).
