# ADR-011 · Grow without placeholder fields

- **Status:** Accepted (2.0)
- **Context:** During design we considered reserving `Cell.media`,
  `Surface.placements` and similar fields for future capabilities. A
  reserved field becomes a promise before its semantics are known, and
  every reader has to decide what an empty value means.
- **Decision:** Do not reserve unimplemented fields. Engine values are
  keyword-only, fully defaulted and add fields only when the feature
  lands. Optional capabilities are defaulted properties or injected
  collaborators.
- **Why:** Ownership and construction determine compatibility. A defaulted
  keyword-only field can be added in a minor without moving positional
  arguments; an empty placeholder cannot be removed later without a break.
- **Consequences:** `tools/growth.py` proves the rule by adding temporary
  defaulted fields to `Surface`, `Constraints`, `ScrollAxis` and `Scroll`
  in a throw-away copy and running the real gates. Images and other media
  wait for their own design (ADR-015).
- **Alternatives:** Reserve empty fields (rejected: unverified semantics
  become contract).
