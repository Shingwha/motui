# ADR-027 · Composition is transparent overlay

- **Status:** Accepted (2.1.2)
- **Context:** 2.0 had no composition primitive. A scene stacked a
  backdrop, content and chrome as separate sections, so overlapping
  widgets had no defined result and a host that wanted a centred badge
  built its own padding. The meaning of a blank cell in a lower layer was
  also undefined: painting a background as ordinary styled spaces made
  every later layer opaque.
- **Decision:** `Line.overlay(base)` and `Surface.overlay(base)` compose
  two values. A cell is transparent when it is a plain space carrying
  `Style()`, no link and no action; a transparent cell keeps the base
  cell. Any other top cell wins and merges `base_style.merge(top_style)`,
  so the lower color shows through while the top attributes win. The
  result is the larger width and height. A double-width glyph is replaced
  as a whole cluster; an empty top row returns the base row. `Stack` renders
  every layer with the same constraints, bottom first, and folds them with
  `Surface.overlay`. Its `child_at` is interaction-first: the first layer
  with a clickable/focusable/hoverable node at the cell wins, then the
  topmost geometric layer. `Align` renders one child with the full
  constraints, measures the painted block (`len(rows)` by the widest row),
  anchors it in a blank frame and clips overflow. Invalid anchors raise
  `ValueError`.
- **Why:** Transparency as "plain unstyled space" lets a scene compose
  without a background flag or a second section order. Merging the styles
  keeps an underlying band visible under emphasis. Whole-glyph replacement
  is the only way to avoid a dangling continuation column. Interaction-first
  hit testing keeps a decorative backdrop from swallowing clicks, while the
  topmost fallback preserves text selection and geometric z-order. Measuring
  the painted block is honest about short rows (`Text` returns them) and
  needs no measure/render split.
- **Consequences:** A component that paints its own full frame blocks the
  layers below it; transparency must be left as plain spaces. A full-width
  child shows no horizontal alignment. `Stack` clips to its constraints.
  Alignment is a composition act, not a layout mode of the child.
- **Alternatives:** Treat a background-colored space as transparent
  (rejected: it is content and a legitimate fill); compose column by column
  across wide glyphs (rejected: corrupts rows); z-order-only hit testing
  (rejected: background canvases eat clicks); add a measure phase to
  `Align` (rejected: ADR-002).
