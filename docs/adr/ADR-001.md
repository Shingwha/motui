# ADR-001 · Surface is the only frame type

- **Status:** Accepted (2.0)
- **Context:** The 1.x render result was a bare `list[Line]` with no
  geometry. A canvas, a plot or any future media had nowhere to live, and
  every consumer had to invent its own width bookkeeping.
- **Decision:** Every component renders through
  `render(Constraints) -> Surface`. `Surface` is the only frame type.
  `Canvas` is a mutable builder that produces a `Surface`; it never writes
  terminal bytes.
- **Why:** Selection, hit testing, golden comparison and overlay
  composition all take one path. Future capabilities can grow inside
  `Surface` without a second channel.
- **Consequences:** `Surface` carries the clipping invariant (`row.width <=
  surface.width` for the builder methods). A second rendering path is
  forbidden; a component may answer `OVERFLOW` content, but a container
  clips it.
- **Alternatives:** Keep `list[Line]` (1.x, rejected); add a parallel
  `rows + media` channel (rejected: two paths to test and paint).
